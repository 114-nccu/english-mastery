# N4 逐頁稿 ＋ N6 產生 HTML

## N4 逐頁稿

---

請依 `runs/round<N>/outline.md` 寫逐頁內容，輸出成 `runs/round<N>/deck.html`。

內容規則：
1. 每頁只能使用該頁 `claims:` 列出的卡片內容。
2. 數字照卡片原文寫，不換算。
3. 每頁最後加一行小字出處，例如「出處：S5-C01（Sangers et al., 2025）」。
4. 研究結論要附上限制；AI-ADVICE 的內容要明白標示「AI 建議」。
5. 用初學者看得懂的中文，專有名詞第一次出現時附英文和一句白話解釋。
6. 每頁重點不超過 4 點。

HTML 規則（檢查腳本依賴這些規則）：
- 單一檔案；CSS、JS 都寫在裡面；不使用外部框架。
- 每頁寫成 `<section class="slide" data-claims="S5-C01,S5-C02">`，標題用 `<h2>`。
- 封面加 `data-type="title"`，參考資料頁加 `data-type="refs"`。
- `.slide { width:1280px; height:720px; overflow:hidden; box-sizing:border-box; }`，外層等比例縮放以適應螢幕。
- 頁碼放在 `<span class="nocheck">`。
- 用左右方向鍵翻頁；不做動畫。
- 理解題（依需求 R08，最多 3 題）：用原生 JS 寫在對應的 `<section>` 裡；選項按下後顯示回饋。題目、選項和解答只能來自該頁 `data-claims` 的內容，不得出新知識。
- 引用 `AI-xx`（AI 教學建議）的頁面，畫面上必須寫「AI 建議」或「教學示例」。
- 參考資料頁的 DOI 做成 `<a href="https://doi.org/...">` 連結。

完成後我會執行 `python scripts/check_deck.py`。
