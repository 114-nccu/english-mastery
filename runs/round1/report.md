## 真正的流程改善

- **N4 預檢**：草稿階段應避免含禁用詞，即使句子意圖是「不保證」；審查內容時同時檢查呈現措辭是否觸發專案規則。
- **來源／裝飾分流**：裝飾性序號不能混入 `check_deck` 的資料數字驗證；引用 ID 以可見但標記為 `nocheck` 的頁尾呈現，實際 ID 仍由 `data-claims` 驗證。
- **N6 功能測試**：光有渲染不溢出仍可能有互動缺陷，因此新增實際按鈕與鍵盤焦點測試，不能把 HTML 渲染 PASS 直接當作功能 PASS。
